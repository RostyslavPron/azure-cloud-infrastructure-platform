# Project Scope

## Business Problem

Organizations moving to the cloud require secure resource deployment,
infrastructure automation, centralized secrets management, and
cost visibility.

This project demonstrates the implementation of a cloud infrastructure
platform on Microsoft Azure that addresses these requirements.

## Objectives

- Deploy cloud resources using Infrastructure as Code
- Implement serverless computing
- Improve security through network controls
- Protect sensitive information using Key Vault
- Automate administration tasks
- Monitor and optimize cloud spending
