# Azure Function Deployment

## Objective

Deploy a serverless compute service using Azure Functions.

## Solution

Implemented a Function App capable of running on demand
without managing underlying infrastructure.

## Key Benefits

- Automatic scaling
- Lower operational overhead
- Pay-per-use pricing
